Drop your photos in this folder, then rebuild the site (npm run build).
- Photos directly in this folder appear under "General".
- Put photos in sub-folders to make filter buttons, e.g. a folder named "Youth" or "Sunday service".
- The file name becomes the caption: "baptism-day.jpg" shows as "Baptism day".
- Photos are shown in file-name order, so start names with 01-, 02- (or a date) to control the order.
- Tip: resize photos to about 1600 px wide (under 500 KB each) at squoosh.app first.
