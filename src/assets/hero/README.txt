HOME PAGE COVER PHOTOS
Every picture in this folder fades in turn at the top of the home page. Nothing else to edit.
- Add a photo: copy it into this folder, then run "npm run site" again (or redeploy).
- Remove a photo: delete it from this folder.
- Order: pictures show in file-name order, so start names with 01-, 02-, 03-.
- Photos are shown WHOLE (nobody is cropped), so any shape works. Landscape about 1920 px wide, under 500 KB, looks best.
- The file name is used as the description for screen readers: "01-sunday-worship.jpg" becomes "Sunday worship".
